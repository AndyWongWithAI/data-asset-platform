# 数据服务接入指南 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 数据服务详情页新增「接入指南」区块，按 API/订阅/数据包三类展示技术接入契约 + 一键复制，补齐技术人员的接入视角。

**Architecture:** 数据层在 `src/data.js` 的 `services[]` 每条加一个 `access` 对象（三种类型异构结构）；UI 层新建可复用 `CopyButton` 组件，在 `DataServiceDetailModule` 详情页「封装资产」之后、「审批链」之前插入「接入指南」区块按 `s.type` 分支渲染。纯前端，无后端改动（services 仍是只读）。

**Tech Stack:** React 18 + Vite 5；`navigator.clipboard.writeText` 前端复制；`node --test` + playwright 测试。

## Global Constraints

- 所有接口地址 / 主题 / 连接地址均为**示例占位**（`demo.intelab.cn` 前缀），非真实可调用，`meta.disclaimer` 不变。
- **不含鉴权/密钥**：`access` 不得出现 `auth`/`key`/`secret`/`token`/`password`/`credential`/`apiKey`/`accessKey` 任一键；界面无密钥展示、无复制密钥按钮。
- 只改技术后台「数据服务」模块（详情页 + CopyButton 组件），**门户侧（src/portal/）不动**。
- 不触碰广发「数据资源目录」术语。
- 每次开发完成后必跑 `npm run test:page`。
- git-guardrails L0：main 只接受 merge 提交，开发走 `git checkout -b task/...` 再 `git merge --no-ff`。

```jsx
import { useState } from 'react';

// 复制按钮：点击复制文本到剪贴板，成功短暂显示「已复制」。纯前端，无后端。
export default function CopyButton({ text }) {
  const [copied, setCopied] = useState(false);
  const copy = async () => {
    try {
      await navigator.clipboard.writeText(text);
      setCopied(true);
      setTimeout(() => setCopied(false), 1500);
    } catch {
      // 复制失败（非 secure context 等）静默忽略
    }
  };
  return (
    <button className="link" onClick={copy}>{copied ? '已复制' : '复制'}</button>
  );
}
```
